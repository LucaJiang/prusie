Performance

These are measurements of the frozen source and settings identified on this page, not of the current unreleased reference-oriented arithmetic defaults. Those changed defaults have not received a new runtime or peak-memory benchmark. Experimental math paths are not universally PIP-qualified; see computational compatibility.

These measurements compare prusie 0.2.4.dev2 with susieR 0.16.6 on 100 GWAS and 100 eQTL locus analyses. They measure the runtime of one fitting call and the peak resident memory (RSS) of a new process for each locus and backend.

Measured 0.2.4.dev2 against susieR 0.16.6.

¹ Geometric mean of per-locus susieR/prusie runtime ratios. ² Median per-locus susieR/prusie ratio of peak resident memory (RSS), including the interpreter and inputs.

Environment: AMD EPYC 9754; Linux x86-64, glibc 2.35; CPython 3.12.2, NumPy 2.2.6; R 4.4.0 with OpenBLAS 0.3.20 (Zen); one numerical thread. NumPy uses its packaged OpenBLAS; the Rust single-effect updates use the optional glibc libmvec AVX2 path. The environment record identifies the loaded libraries and binary hashes.

Data

The data cover 100 genomic windows: 100 analyses of one FinnGen R10 inflammatory bowel disease GWAS (K11_IBD_STRICT; n = 412181) and 100 BLUEPRINT monocyte eQTL analyses (QTD000021; n = 191), representing 83 distinct genes. The interval metadata contain 0 overlapping window pairs. Analyses share study participants and reference samples; the 200 trait analyses are not 200 independent loci.

Each analysis contains 103–4,162 aligned variants. Signed LD comes from external 1000 Genomes samples: 99 FIN founders for GWAS and 525 EUR founders for eQTL. Both analyses use the same variant intersection within each window, with the respective LD matrix. See the input sources for study pages and harmonization details.

Methods

Timing surrounds the public susie_rss call, including input validation, RSS preparation, IBSS, posterior summaries and credible-set construction. Imports, file reads, explicit garbage collection and exports are outside the clock. One warm-up precedes seven repeats; the median represents each locus/backend. Backends run sequentially, with their order alternating between cases. The machine is shared, so the results include repeat variability.

The speed-up for a locus is its median susieR runtime divided by its median prusie runtime. The main table reports the geometric mean of these ratios. The memory ratio is susieR peak RSS divided by prusie peak RSS for each locus; the table reports their median. Neither ratio is a ratio of the group medians.

Memory is measured separately from timing in a new process for each locus/backend. The process fits once and retains the result; its high-water mark includes the interpreter, imports and input loading. Current RSS is also sampled before and during fitting. The sampled increment subtracts the RSS immediately before fitting from the sampled fit peak. Sampling targets 2 ms; short allocations can be missed, making sampled peaks and increments lower bounds. The largest observed gaps are 35.1 ms for prusie and 404.5 ms for R. The process high-water mark is the primary memory measure. KiB is divided by 1024 to obtain MiB.

All 200 analyses are included, including iteration-limit and empty-CS results. Settings are L=5, tol=0.001, max_iter=100, scaled_prior_variance=0.2, fixed residual variance 1, estimated prior variance, uniform variant priors, no null column, standardization, coverage 0.95 and minimum absolute correlation 0.5. Purity uses every pair of variants in each set. Both implementations skip optional eigenvalue/projection diagnostics; prusie's check_input=False retains finite-value, symmetry, diagonal and range checks. Process address space is limited to 16 GiB. The results apply to these inputs, binaries and hardware; implementation agreement does not establish model validity.

Dense-matrix scaling

A separate deterministic computational fixture uses L=5, n=5000, AR(1) correlation ρ=0.4, effects [8,7,6] at [p//5,p//2,4p//5], and a 0.15 cos(0.73j) background. It uses tol=0.001, max_iter=100, estimated prior variance and fixed residual variance 1.

All six sizes meet the PIP comparison criterion; the largest absolute difference is 2.62e-11, with matching convergence flags and CS membership. At p=20,000, prusie takes three sweeps and susieR four. The timings include this iteration-count difference.
