Performance

These measurements compare prusie with the pinned R implementation. They do not establish a speed improvement over an earlier prusie version. The dev2 stopping and prior-variance changes correct numerical behavior; no direct before/after runtime claim is made for those fixes. Individual optimizations require a separate complete-call comparison in which more than half of the fixed applicable cases have lower median runtime.

Each column is a separate across-case median. Full-process peak is a fresh process high-water mark. The prefit baseline is current resident memory after imports, inputs and GC. The sampled increment is the fit-stage sampled peak minus that same current baseline, never a difference of historical high-water marks. Target sampling interval is 2 ms; observed maximum intervals are retained. Short allocation spikes can be missed, so sampled peaks and increments are lower bounds.

The largest observed sampling gaps on the real panel were 35.1 ms for prusie and 404.5 ms for R. Thus the target interval is not a guaranteed resolution, particularly for short fits. Full-process high-water marks remain the primary memory measure.

Controlled dense scaling

This separate deterministic panel fixes L=5, n=5000, AR(1) correlation rho=0.4 and effects [8,7,6] at [p//5,p//2,4p//5], with 0.15 cos(0.73j) background. It uses tol=0.001, max_iter=100, optimized prior variance and fixed residual variance 1. It is a computational measurement fixture.

Independent validation passes the PIP criterion for all six scales (maximum absolute difference 2.62×10⁻¹¹), with matching convergence flags and CS members. At p=20,000, prusie takes three sweeps and R four; their ELBO trace lengths therefore differ. Complete-call timing retains that observed iteration difference.

Current measurement protocol and records

The full public-call boundary and matched settings are detailed under Methods below. One warmup precedes seven retained repeats; backends run sequentially with one numerical thread. Imports, file reads, explicit GC and exports are outside each fit clock. The machine was shared; host pressure and repeat variability were recorded. Process address space was limited to 16 GiB. The current environment record identifies AMD EPYC 9754, Linux x86-64/glibc 2.35, CPython 3.12.2, NumPy 2.2.6, R 4.4.0/OpenBLAS 0.3.20 and the actual native/BLAS library hashes. Complete-call ratios do not isolate individual kernel costs.

Historical comparison: 0.2.3rc4

This historical comparison measures complete fine-mapping calls in prusie 0.2.3rc4 and susieR 0.16.6. The results below reanalyze retained measurements from 6 October 2026; they retain the original executable identities.

Real-data panel

The fixed panel contains 100 genomic windows: 100 analyses of one FinnGen R10 inflammatory bowel disease GWAS (K11_IBD_STRICT; n = 412181) and 100 BLUEPRINT monocyte eQTL analyses (QTD000021; n = 191), representing 83 distinct genes. The interval metadata contain 0 overlapping window pairs. Analyses share study participants and reference samples; the 200 trait analyses are not 200 independent loci.

Signed LD was calculated from external 1000 Genomes reference samples: 99 FIN founders for GWAS and 525 EUR founders for eQTL. Both analyses use the same aligned variant intersection within each window, with their respective LD. The input manifest preserves allele/order checks, exclusions and source hashes.

Methods

Every successful pair with matching settings and seven finite positive retained times is included, regardless of convergence, credible-set presence or numerical difference. Each fit has a 100-iteration maximum, with early convergence using its actual iteration count. The pair reaching 100 iterations on both sides is included. Failed or missing records retain explicit statuses and null metrics. Numerical validity and timing eligibility are separate fields.

Timing surrounds the full public susie_rss call: validation, RSS preparation, IBSS and posterior/credible-set summaries. Imports, file reads, explicit garbage collection and exports are outside the clock. After one warmup, seven calls are retained with one result held at a time. Backends run sequentially, with their order alternating between cases; one numerical thread is used. Runtime uses a monotonic high-resolution clock. Peak memory is measured independently in a fresh process per case/backend, fitting once and retaining the full result; Linux process high-water KiB is divided by 1024 to obtain MiB. SuSiE-RSS names the summary-statistic model; process RSS in the measurement record means resident set size.

The machine was an AMD EPYC 9754 system running Linux x86-64 with glibc 2.35. The measured software was CPython 3.12.2, NumPy 2.2.6 and R 4.4.0. R loaded OpenBLAS 0.3.20 (Zen, one thread); NumPy loaded its packaged OpenBLAS and the native SER used the recorded optional glibc libmvec AVX2 path. Full loaded-library identities, dependency versions and executable hashes are in the protocol and environment record. These measurements apply to the recorded binary and machine. Complete-call ratios do not isolate R initialization overhead, a particular optimization or numerical-kernel cost; those claims require separate profiling or ablation measurements.

Real analyses use L=5, tol=0.001, max_iter=100, scaled_prior_variance=0.2, fixed residual variance 1, optimized prior variance, normalized uniform priors, no null column, standardization, coverage 0.95 and minimum absolute correlation 0.5. Complete matrix purity is used. check_input=False leaves finite, symmetry, diagonal and range validation active; additional eigenvalue/projection diagnostics are disabled in both compared settings. All parameters are in the case records.
