Statistical model

Fine-mapping asks which variants in a region contribute to a trait when nearby variants are correlated. Several variants can therefore explain much the same association signal. SuSiE represents multiple effects while retaining uncertainty about the variant responsible for each one. prusie fits the Gaussian SuSiE model from association summary statistics and signed LD, or from centered sufficient statistics.

Data, notation and scale

Let nnn be the study sample size, ppp the number of variants and LLL the maximum number of single-effect components. The centered design matrix X∈Rn×p\mathbf X\in\mathbb R^{n\times p}X∈Rn×p contains the predictors and the centered response is y∈Rn\mathbf y\in\mathbb R^ny∈Rn. Their sufficient statistics are

Q=XTX,g=XTy,sy=yTy. \mathbf Q=\mathbf X^T\mathbf X,\qquad \mathbf g=\mathbf X^T\mathbf y,\qquad s_y=\mathbf y^T\mathbf y. Q=XTX,g=XTy,sy​=yTy.

The LD correlation matrix R\mathbf RR refers to the same variant order and counted effect alleles. The residual variance is σ2\sigma^2σ2; component ℓ\ellℓ has nonzero-effect prior variance VℓV_\ellVℓ​, and πj\pi_jπj​ is its prior probability of choosing variant jjj. prusie uses the same variant weights for all components.

By default, predictors are standardized using their sample standard deviations dj=Qjj/(n−1)d_j=\sqrt{Q_{jj}/(n-1)}dj​=Qjj​/(n−1)​. Inference then uses D−1QD−1\mathbf D^{-1}\mathbf Q\mathbf D^{-1}D−1QD−1 and D−1g\mathbf D^{-1}\mathbf gD−1g, where D=diag⁡(d1,…,dp)\mathbf D=\operatorname{diag}(d_1,\ldots,d_p)D=diag(d1​,…,dp​), while the response scale stays fixed. A zero predictor scale is replaced by one for this transformation. Below, Q\mathbf QQ and g\mathbf gg in the updates denote these working sufficient statistics. Setting standardize=False retains the supplied predictor scale. coef converts the posterior mean back by dividing by the stored predictor scales. Centering and any covariate adjustment must already be consistent across the caller's summaries; this API does not fit covariates.

A sum of single effects

The sampling model is Gaussian regression:

y=Xb+ε,ε∼N(0,σ2In),b=∑ℓ=1Lbℓ. \begin{aligned} \mathbf y&=\mathbf X\mathbf b+\boldsymbol\varepsilon, &\boldsymbol\varepsilon&\sim N(\mathbf0,\sigma^2\mathbf I_n),\\ \mathbf b&=\sum_{\ell=1}^{L}\mathbf b_\ell. \end{aligned} yb​=Xb+ε,=ℓ=1∑L​bℓ​.​ε∼N(0,σ2In​),

Each component chooses one variant and gives it a Gaussian effect:

γℓ∼Categorical⁡(π1,…,πp),aℓ∼N(0,Vℓ),bℓ=aℓeγℓ. \begin{aligned} \gamma_\ell&\sim\operatorname{Categorical}(\pi_1,\ldots,\pi_p),\\ a_\ell&\sim N(0,V_\ell), &\mathbf b_\ell&=a_\ell\mathbf e_{\gamma_\ell}. \end{aligned} γℓ​aℓ​​∼Categorical(π1​,…,πp​),∼N(0,Vℓ​),​bℓ​​=aℓ​eγℓ​​.​

Here ej\mathbf e_jej​ is the vector with a one at position jjj and zeros elsewhere. The location γℓ\gamma_\ellγℓ​ describes which variant carries the component; aℓa_\ellaℓ​ describes its effect size. Uniform weights, πj=1/p\pi_j=1/pπj​=1/p, are the default. prior_weights changes these probabilities. scaled_prior_variance initializes VℓV_\ellVℓ​ relative to sy/(n−1)s_y/(n-1)sy​/(n−1).

LLL bounds the number of component effects. Multiple components can select the same variant, and an estimated Vℓ=0V_\ell=0Vℓ​=0 removes that component's nonzero effect. The number of returned credible sets additionally depends on posterior mass, LD purity and deduplication. Thus LLL, the number of distinct causal variants, and the number of reported sets describe different quantities.

Component posteriors and effect means

SuSiE fits a variational approximation that factorizes between components:

q(b1,…,bL)=∏ℓ=1Lqℓ(bℓ). q(\mathbf b_1,\ldots,\mathbf b_L)=\prod_{\ell=1}^{L}q_\ell(\mathbf b_\ell). q(b1​,…,bL​)=ℓ=1∏L​qℓ​(bℓ​).

Within a component, uncertainty about the chosen variant and its effect remains coupled. The returned arrays represent

αℓj=qℓ(γℓ=j),μℓj=Eq[aℓ∣γℓ=j],Mℓj(2)=Eq[aℓ2∣γℓ=j]=μℓj2+τℓj2. \begin{aligned} \alpha_{\ell j}&=q_\ell(\gamma_\ell=j),\\ \mu_{\ell j}&=\mathbb E_q[a_\ell\mid\gamma_\ell=j],\\ M^{(2)}_{\ell j}&=\mathbb E_q[a_\ell^2\mid\gamma_\ell=j] =\mu_{\ell j}^2+\tau_{\ell j}^2. \end{aligned} αℓj​μℓj​Mℓj(2)​​=qℓ​(γℓ​=j),=Eq​[aℓ​∣γℓ​=j],=Eq​[aℓ2​∣γℓ​=j]=μℓj2​+τℓj2​.​

alpha, mu and mu2 correspond to α\alphaα, μ\muμ and M(2)M^{(2)}M(2). In particular, mu2 includes the conditional posterior variance τℓj2\tau_{\ell j}^2τℓj2​; it is neither the square of mu alone nor a variance array. The component's marginal mean is mℓ=αℓ⊙μℓ\mathbf m_\ell=\boldsymbol\alpha_\ell\odot\boldsymbol\mu_\ellmℓ​=αℓ​⊙μℓ​ and the total mean is m=∑ℓmℓ\mathbf m=\sum_\ell\mathbf m_\ellm=∑ℓ​mℓ​. A large conditional mean need not imply a large marginal mean if that variant has little component probability. coef reports mj/djm_j/d_jmj​/dj​ on the input predictor scale. The precise response and coefficient units for each RSS input route are described below.

One single-effect regression

To update component ℓ\ellℓ, hold the other component means fixed and form

rℓ=g−Q∑k≠ℓmk,b^ℓj=rℓj/Qjj,sj2=σ2/Qjj. \begin{aligned} \mathbf r_\ell&=\mathbf g-\mathbf Q\sum_{k\ne\ell}\mathbf m_k,\\ \widehat b_{\ell j}&=r_{\ell j}/Q_{jj}, &s_j^2&=\sigma^2/Q_{jj}. \end{aligned} rℓ​bℓj​​=g−Qk=ℓ∑​mk​,=rℓj​/Qjj​,​sj2​​=σ2/Qjj​.​

rℓ\mathbf r_\ellrℓ​ is a length-ppp crossproduct residual. It is the crossproduct of X\mathbf XX with an individual-level residual, rather than the length-nnn residual itself. For Qjj>0Q_{jj}>0Qjj​>0, a Gaussian single-effect regression (SER) compares the effect prior with a zero effect at each candidate variant:

log⁡BFℓj=−12log⁡(1+Vℓsj2)+b^ℓj 2Vℓ2sj2(sj2+Vℓ). \log\mathrm{BF}_{\ell j} =-\frac12\log\left(1+\frac{V_\ell}{s_j^2}\right) +\frac{\widehat b_{\ell j}^{\,2}V_\ell} {2s_j^2(s_j^2+V_\ell)}. logBFℓj​=−21​log(1+sj2​Vℓ​​)+2sj2​(sj2​+Vℓ​)bℓj2​Vℓ​​.

Combining the Bayes factor with the variant prior gives

αℓj=πjBFℓj∑kπkBFℓk,μℓj=VℓVℓ+sj2b^ℓj,τℓj2=Vℓsj2Vℓ+sj2. \begin{aligned} \alpha_{\ell j}&=\frac{\pi_j\mathrm{BF}_{\ell j}} {\sum_k\pi_k\mathrm{BF}_{\ell k}},\\ \mu_{\ell j}&=\frac{V_\ell}{V_\ell+s_j^2}\widehat b_{\ell j}, &\tau_{\ell j}^2&=\frac{V_\ell s_j^2}{V_\ell+s_j^2}. \end{aligned} αℓj​μℓj​​=∑k​πk​BFℓk​πj​BFℓj​​,=Vℓ​+sj2​Vℓ​​bℓj​,​τℓj2​​=Vℓ​+sj2​Vℓ​sj2​​.​

The posterior mean shrinks the marginal estimate toward zero, most strongly when its sampling variance is large relative to the prior variance. Prior weights affect the probability of a location; uncertainty can remain spread across correlated variants with similar evidence. The formulas give the ordinary positive-variance model. The implementation's weight smoothing and zero-information conventions are collected in Inputs. lbf_variable stores the variant log Bayes factors, before variant prior weights are added; lbf stores the component's log weighted evidence.

Sequential IBSS and variance estimation

Iterative Bayesian stepwise selection (IBSS) repeatedly applies SER. At initialization, the component means are zero, each alpha row is uniform, and the variances use the supplied initial values. Within a sweep, later components use the newly updated means of earlier components:

initialize component means, variances and their matrix products
for each sweep, up to max_iter:
    for each component in order:
        remove its old contribution from the fitted crossproduct
        form its crossproduct residual
        select V and compute the SER posterior (EM updates V after the posterior)
        store the component evidence, KL and new matrix product
    evaluate expected residual sum of squares and ELBO
    test convergence after the first sweep
    if converged: stop
    if requested: update residual variance for the next sweep
trim components below prior_tol and construct summaries

For estimate_prior_method="optim", the component update maximizes the SER log marginal likelihood log⁡∑jπjBFℓj(V)\log\sum_j\pi_j\mathrm{BF}_{\ell j}(V)log∑j​πj​BFℓj​(V) using a Brent search over log variance, with the implementation's smoothed weights. The candidate is compared with the previous variance, then with V=0V=0V=0. check_null_threshold requires the selected variance to improve on the null log likelihood by more than that threshold. simple performs this null comparison at the existing VVV without the continuous search.

EM first computes the posterior at the current VℓV_\ellVℓ​, then sets Vℓ←∑jαℓjMℓj(2)V_\ell\leftarrow\sum_j\alpha_{\ell j}M^{(2)}_{\ell j}Vℓ​←∑j​αℓj​Mℓj(2)​ for the next update. It does not apply the optim/simple null Bayes-factor comparison. The stored component evidence and KL come from that just-computed posterior. With estimate_prior_variance=False, SER uses fixed initialized VVV and bypasses both estimation and the null comparison; final low-variance trimming still applies.

The variational objective balances expected data fit against departure from the prior:

L(q)=Eq[log⁡p(y∣b,σ2)]−∑ℓ=1LKL⁡{qℓ(bℓ)∥pℓ(bℓ)}. \mathcal L(q)=\mathbb E_q[\log p(\mathbf y\mid\mathbf b,\sigma^2)] -\sum_{\ell=1}^{L}\operatorname{KL}\{q_\ell(\mathbf b_\ell)\|p_\ell(\mathbf b_\ell)\}. L(q)=Eq​[logp(y∣b,σ2)]−ℓ=1∑L​KL{qℓ​(bℓ​)∥pℓ​(bℓ​)}.

The Gaussian likelihood needs the expected residual sum of squares, including posterior effect uncertainty. Implementation derives this from mu2 and the retained component products. The objective is stored at the current σ2\sigma^2σ2 before a possible residual-variance update. If stopping has not occurred and estimation is enabled, the update is σ2←ER2/n\sigma^2\leftarrow\mathrm{ER2}/nσ2←ER2/n, including after the last allowed sweep. Consequently a fit that stops at the iteration limit can return a newer sigma2 than the value used for its last stored ELBO. A converged fit skips that update. Final trimming does not recompute the ELBO or fitted crossproduct. Results defines the stopping rule, exceptional fallback and returned states in one place.

From summaries to working sufficient statistics

With actual centered sufficient statistics, the Gaussian likelihood depends on the data through Q\mathbf QQ, g\mathbf gg, sys_ysy​ and nnn; an individual-level matrix need not be retained. susie_suff_stat uses these quantities directly. RSS constructs working crossproducts from marginal associations and LD. When the LD and summaries describe the same data and preprocessing, this can recover the regression quantities. External LD instead supplies an approximation to the study's correlation structure.

Known sample size and Wald z statistics

For the default response scale, prusie applies the finite-sample Wald/PVE adjustment and constructs

z~j=zjn−1zj2+n−2,Q=(n−1)R,g=n−1 z~,sy=n−1. \begin{aligned} \widetilde z_j&=z_j\sqrt{\frac{n-1}{z_j^2+n-2}},\\ \mathbf Q&=(n-1)\mathbf R, &\mathbf g&=\sqrt{n-1}\,\widetilde{\mathbf z}, &s_y&=n-1. \end{aligned} zj​Q​=zj​zj2​+n−2n−1​​,=(n−1)R,​g​=n−1​z,​sy​​=n−1.​

When bhat, shat, n and var_y are all supplied, write Aj=(n−1)/(zj2+n−2)A_j=(n-1)/(z_j^2+n-2)Aj​=(n−1)/(zj2​+n−2) and vy=var_yv_y=\mathtt{var\_y}vy​=var_y. The reconstruction is

The constructed crossproduct is averaged with its transpose to remove rounding asymmetry. Subsequent predictor standardization uses these reconstructed diagonals. coef reverses that standardization and has the original predictor and phenotype units under the supplied marginal-regression assumptions. mu and mu2 remain on the fitted predictor scale.

Missing sample size

When nnn is omitted, prusie uses the noncentrality-parameter likelihood with Q=R\mathbf Q=\mathbf RQ=R, g=z\mathbf g=\mathbf zg=z, sy=1s_y=1sy​=1 and internal n=2n=2n=2. Predictor standardization is disabled, and prior_variance initializes VVV (default 50). bhat/shat supplies z in exactly the same way. A supplied var_y is checked for validity and recorded but does not alter these working quantities. coef then describes noncentrality effects, rather than effects per original genotype/phenotype unit. A warning records this missing-n path.

Interpreting the LD approximation

LD is signed correlation rrr, aligned to the same variants and effect alleles as the summaries; Inputs gives the required transformations. Residual-variance estimation relies on in-sample LD consistent with the summaries. With an external panel, RSS defaults to fixed variance so that sampling noise or mismatch in LD is not interpreted as residual variance. The approximation still depends on ancestry, sample size and data preparation. For case-control GWAS, prusie uses the Gaussian summary approximation to the association statistics; it does not interpret the binary phenotype as a fitted individual-level Gaussian response. Quantitative eQTL summaries use their reported regression scale and sample size.

PIP and credible sets

For active components A\mathcal AA, the variational marginal inclusion probability is

PIPj=1−∏ℓ∈A(1−αℓj). \mathrm{PIP}_j=1-\prod_{\ell\in\mathcal A}(1-\alpha_{\ell j}). PIPj​=1−ℓ∈A∏​(1−αℓj​).

The product is the approximate probability that no active component selects variant jjj. Each alpha row sums to one, whereas the sum of PIPs over variants can exceed one because the model allows multiple effects. The resulting PIPs are (0.82, 0.83, 0.145), whose sum is 1.795.

A component credible set accumulates variants in decreasing alpha order until its mass reaches coverage. For alpha (0.50,0.48,0.02)(0.50,0.48,0.02)(0.50,0.48,0.02) and a requested mass of 0.95, the two leading variants are selected:

The actual posterior mass is 0.98. If the two variants have signed correlation r=−0.9r=-0.9r=−0.9, the minimum, mean and median absolute pairwise correlation are all 0.9, so the set passes min_abs_corr=0.5.

The selected mass is the component posterior probability assigned to those members; the requested mass is the selection target. Purity summarizes absolute pairwise LD inside the selected set. Here either of two highly correlated variants could carry the effect, so their joint mass is high even though neither is individually well localized. Repeated-sampling coverage is the frequency with which constructed sets contain a true effect over repeated datasets; it is a calibration property, distinct from the mass computed for this fit. Results describes activity thresholds, stable ordering, deduplication and returned component IDs.

The arithmetic examples here and on the implementation page are generated and checked by model_examples.py. They illustrate probability and linear algebra; the separately fitted 500-variant toy example demonstrates the complete API.

Methods and implementation references

The summary-statistic construction follows Zou et al. (2022), Fine-mapping from summary data with the “Sum of Single Effects” model.
