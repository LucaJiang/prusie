Statistical model

Fine-mapping aims to identify variants that affect a trait, but linkage disequilibrium (LD) can make several nearby variants consistent with the same association signal. prusie uses the sum of single effects (SuSiE) model to represent multiple effects while quantifying uncertainty about which variants carry them.

SuSiE is a Bayesian variable selection model for linear regression with Gaussian errors. It represents the vector of variant effects as a sum of single-effect components, each with at most one nonzero effect.

prusie can fit this model using individual-level data, sufficient statistics computed from centered data, or association summary statistics together with an LD correlation matrix. The sections below develop the model with Gaussian effect priors, starting with the data and notation; additional model options are introduced later.

Data, notation and scale

Let nnn be the study sample size, ppp the number of variants and LLL the maximum number of single-effect components. The centered design matrix X∈Rn×p\mathbf X\in\mathbb R^{n\times p}X∈Rn×p contains the predictors and the centered response is y∈Rn\mathbf y\in\mathbb R^ny∈Rn. Their sufficient statistics are

Q=XTX,g=XTy,sy=yTy. \mathbf Q=\mathbf X^T\mathbf X,\qquad \mathbf g=\mathbf X^T\mathbf y,\qquad s_y=\mathbf y^T\mathbf y. Q=XTX,g=XTy,sy​=yTy.

The LD correlation matrix R\mathbf RR refers to the same variant order and effect alleles. The residual variance is σ2\sigma^2σ2; single effect ℓ\ellℓ has prior effect variance VℓV_\ellVℓ​ (written σ02\sigma_0^2σ02​ in some references), and πj\pi_jπj​ is the prior probability that it is located at variant jjj. prusie uses the same prior weights for all single effects.

With standardize=True (the default), each centered predictor column is divided by its sample standard deviation dj=Qjj/(n−1)d_j=\sqrt{Q_{jj}/(n-1)}dj​=Qjj​/(n−1)​. Each nonconstant column then has unit sample variance, while the response remains in its supplied units. For a constant column, the divisor is set to one to avoid division by zero. With standardize=False, all divisors are one and the predictor units are unchanged.

The corresponding sufficient statistics used for fitting are D−1QD−1\mathbf D^{-1}\mathbf Q\mathbf D^{-1}D−1QD−1 and D−1g\mathbf D^{-1}\mathbf gD−1g, where D=diag⁡(d1,…,dp)\mathbf D=\operatorname{diag}(d_1,\ldots,d_p)D=diag(d1​,…,dp​). In the regression and updates below, the predictor matrix is on this working scale, and Q\mathbf QQ and g\mathbf gg denote the working sufficient statistics.

Effect estimates are computed on the working predictor scale. The coef property divides each posterior mean coefficient by its stored predictor scale factor to express the effect per unit of the input predictor. For summary-statistic inputs, these units depend on how the regression quantities are constructed; see From summaries to working sufficient statistics.

Standardization is separate from centering and covariate adjustment. Supplied summary statistics and sufficient statistics must already reflect consistent centering and any covariate adjustment; the fitting routines do not estimate additional covariate effects.

A sum of single effects

The sampling model is Gaussian regression:

y=Xb+ε,ε∼N(0,σ2In),b=∑ℓ=1Lbℓ. \begin{aligned} \mathbf y&=\mathbf X\mathbf b+\boldsymbol\varepsilon, &\boldsymbol\varepsilon&\sim N(\mathbf0,\sigma^2\mathbf I_n),\\ \mathbf b&=\sum_{\ell=1}^{L}\mathbf b_\ell. \end{aligned} yb​=Xb+ε,=ℓ=1∑L​bℓ​.​ε∼N(0,σ2In​),

Each single effect, indexed by ℓ=1,…,L\ell=1,\ldots,Lℓ=1,…,L, is located at one variant and has a Gaussian effect size:

γℓ∼Categorical⁡(π1,…,πp),aℓ∼N(0,Vℓ),bℓ=aℓeγℓ. \begin{aligned} \gamma_\ell&\sim\operatorname{Categorical}(\pi_1,\ldots,\pi_p),\\ a_\ell&\sim N(0,V_\ell),\\ \mathbf b_\ell&=a_\ell\mathbf e_{\gamma_\ell}. \end{aligned} γℓ​aℓ​bℓ​​∼Categorical(π1​,…,πp​),∼N(0,Vℓ​),=aℓ​eγℓ​​.​

For component ℓ\ellℓ, γℓ\gamma_\ellγℓ​ selects a variant from 1,…,p1,\ldots,p1,…,p, and aℓa_\ellaℓ​ is its effect size. The vector ej\mathbf e_jej​ has a one in position jjj and zeros elsewhere, so bℓ\mathbf b_\ellbℓ​ places the effect at the selected variant and assigns zero to every other variant.

The prior probability of selecting variant jjj is πj\pi_jπj​. By default, all variants are equally likely (πj=1/p\pi_j=1/pπj​=1/p); prior_weights allows unequal probabilities. The effect-size prior is centered at zero with variance VℓV_\ellVℓ​. In this Gaussian model, its initial value is scaled_prior_variance times the response sample variance sy/(n−1)s_y/(n-1)sy​/(n−1). This parameter defaults to 0.2 and accepts either a shared value or a separate value for each component.

LLL sets the maximum number of single-effect components available to the model. A component with Vℓ=0V_\ell=0Vℓ​=0 contributes no effect, and several components can select the same variant. Choosing LLL therefore does not assume that exactly LLL distinct variants affect the trait. Credible sets summarize uncertainty about component locations; sets from inactive components or with low LD purity are excluded by default, and duplicate sets are removed. The number of reported credible sets therefore need not equal LLL or the number of causal variants.

Single-effect posteriors and effect means

SuSiE uses a variational approximation that factorizes over the single effects:

q(b1,…,bL)=∏ℓ=1Lqℓ(bℓ). q(\mathbf b_1,\ldots,\mathbf b_L)=\prod_{\ell=1}^{L}q_\ell(\mathbf b_\ell). q(b1​,…,bL​)=ℓ=1∏L​qℓ​(bℓ​).

Within a single effect, the uncertainty about its location and about its size remain coupled. The returned arrays represent

αℓj=qℓ(γℓ=j),μℓj=Eq[aℓ∣γℓ=j],Mℓj(2)=Eq[aℓ2∣γℓ=j]=μℓj2+τℓj2. \begin{aligned} \alpha_{\ell j}&=q_\ell(\gamma_\ell=j),\\ \mu_{\ell j}&=\mathbb E_q[a_\ell\mid\gamma_\ell=j],\\ M^{(2)}_{\ell j}&=\mathbb E_q[a_\ell^2\mid\gamma_\ell=j] =\mu_{\ell j}^2+\tau_{\ell j}^2. \end{aligned} αℓj​μℓj​Mℓj(2)​​=qℓ​(γℓ​=j),=Eq​[aℓ​∣γℓ​=j],=Eq​[aℓ2​∣γℓ​=j]=μℓj2​+τℓj2​.​

The result arrays alpha, mu and mu2 store the component inclusion probabilities, conditional posterior means and conditional posterior second moments defined above. Rows correspond to single-effect components and columns to variants; τℓj2\tau_{\ell j}^2τℓj2​ denotes the conditional posterior variance.

The posterior mean contribution of component ℓ\ellℓ is obtained by weighting its conditional means by the component inclusion probabilities: mℓ=αℓ⊙μℓ\mathbf m_\ell=\boldsymbol\alpha_\ell\odot\boldsymbol\mu_\ellmℓ​=αℓ​⊙μℓ​, where ⊙\odot⊙ denotes elementwise multiplication. Summing over components gives the total posterior mean m=∑ℓmℓ\mathbf m=\sum_\ell\mathbf m_\ellm=∑ℓ​mℓ​. The coef property returns mj/djm_j/d_jmj​/dj​ on the input predictor scale. For RSS fits, the units depend on the input route, as described under From summaries to working sufficient statistics.

One single-effect regression

To update effect ℓ\ellℓ, the posterior means of the other effects are held fixed and

rℓ=g−Q∑k≠ℓmk,b^ℓj=rℓj/Qjj,sj2=σ2/Qjj. \begin{aligned} \mathbf r_\ell&=\mathbf g-\mathbf Q\sum_{k\ne\ell}\mathbf m_k,\\ \widehat b_{\ell j}&=r_{\ell j}/Q_{jj},\\ s_j^2&=\sigma^2/Q_{jj}. \end{aligned} rℓ​bℓj​sj2​​=g−Qk=ℓ∑​mk​,=rℓj​/Qjj​,=σ2/Qjj​.​

The crossproduct residual rℓ\mathbf r_\ellrℓ​ contains one entry per variant. Each entry rℓjr_{\ell j}rℓj​ is the inner product of predictor column jjj with the response residual after subtracting the posterior mean contributions of all components except ℓ\ellℓ. For Qjj>0Q_{jj}>0Qjj​>0, the Gaussian single-effect regression (SER) gives, for each variant, the Bayes factor of a nonzero effect with prior N(0,Vℓ)N(0,V_\ell)N(0,Vℓ​) against no effect:

log⁡BFℓj=−12log⁡(1+Vℓsj2)+b^ℓj 2Vℓ2sj2(sj2+Vℓ). \log\mathrm{BF}_{\ell j} =-\frac12\log\left(1+\frac{V_\ell}{s_j^2}\right) +\frac{\widehat b_{\ell j}^{\,2}V_\ell} {2s_j^2(s_j^2+V_\ell)}. logBFℓj​=−21​log(1+sj2​Vℓ​​)+2sj2​(sj2​+Vℓ​)bℓj2​Vℓ​​.

Combining the Bayes factor with the variant prior gives

αℓj=πjBFℓj∑kπkBFℓk,μℓj=VℓVℓ+sj2b^ℓj,τℓj2=Vℓsj2Vℓ+sj2. \begin{aligned} \alpha_{\ell j}&=\frac{\pi_j\mathrm{BF}_{\ell j}} {\sum_k\pi_k\mathrm{BF}_{\ell k}},\\ \mu_{\ell j}&=\frac{V_\ell}{V_\ell+s_j^2}\widehat b_{\ell j},\\ \tau_{\ell j}^2&=\frac{V_\ell s_j^2}{V_\ell+s_j^2}. \end{aligned} αℓj​μℓj​τℓj2​​=∑k​πk​BFℓk​πj​BFℓj​​,=Vℓ​+sj2​Vℓ​​bℓj​,=Vℓ​+sj2​Vℓ​sj2​​.​

The probabilities αℓj\alpha_{\ell j}αℓj​ describe uncertainty about the effect's location, combining the prior weights with evidence from the current residual. Correlated variants with similar evidence can share the posterior probability. Conditional on selecting variant jjj, the posterior mean μℓj\mu_{\ell j}μℓj​ shrinks its residual-based estimate b^ℓj\widehat b_{\ell j}bℓj​ toward zero. Shrinkage is stronger when the sampling variance sj2s_j^2sj2​ is large relative to the prior variance VℓV_\ellVℓ​.

lbf_variable stores log⁡BFℓj\log\mathrm{BF}_{\ell j}logBFℓj​ for each variant before prior weighting. lbf stores log⁡∑jπjBFℓj\log\sum_j\pi_j\mathrm{BF}_{\ell j}log∑j​πj​BFℓj​ for each component, summarizing its evidence after averaging over the possible variant locations.

These formulas assume Vℓ>0V_\ell>0Vℓ​>0 and Qjj>0Q_{jj}>0Qjj​>0. Inputs describes how prusie smooths prior weights and handles columns without information.

Sequential IBSS and variance estimation

Iterative Bayesian stepwise selection (IBSS) updates one single-effect component at a time. A sweep is one pass through all components. Each update uses the latest posterior means of the other components: those already updated in the current sweep and those still carrying their values from the previous sweep. At a cold start, the posterior means are zero, each row of alpha is uniform, and the prior and residual variances take their initial values.

initialize component means, variances and their matrix products
for each sweep, up to max_iter:
    for each component in order:
        remove its old contribution from the fitted crossproduct
        form its crossproduct residual
        select V and compute the SER posterior (EM updates V after the posterior)
        store the component evidence, KL and new matrix product
    if requested: check prior variance using the current residual variance
    evaluate expected residual sum of squares and ELBO
    record diagnostics and apply the stopping rule
    if converged, an eligible cycle stop, or numerical failure: stop
    if requested: update residual variance
trim components below prior_tol and construct summaries

Prior variance estimation

When estimate_prior_variance=True, the prior variance is estimated within each component update. estimate_prior_method selects the procedure:

  • optim maximizes the SER log marginal likelihood log⁡∑jπjBFℓj(V)\log\sum_j\pi_j\mathrm{BF}_{\ell j}(V)log∑j​πj​BFℓj​(V) over log⁡V∈[−30,15]\log V\in[-30,15]logV∈[−30,15] using Brent's method and the smoothed prior weights. The candidate replaces the current variance only if its log marginal likelihood is at least as large. The selected variance is then compared with zero: it is retained only if its log marginal likelihood exceeds that at V=0V=0V=0 by more than check_null_threshold; otherwise it is set to zero.
  • simple compares the current variance with zero using the same check_null_threshold rule, without searching for a new positive variance.
  • EM first computes the posterior using the current VℓV_\ellVℓ​, then sets Vℓ←∑jαℓjMℓj(2)V_\ell\leftarrow\sum_j\alpha_{\ell j}M^{(2)}_{\ell j}Vℓ​←∑j​αℓj​Mℓj(2)​ for the next update of that component. The stored Bayes factors and KL divergence refer to the posterior computed before this variance update. EM does not perform the comparison with zero.

With estimate_prior_variance=False, the supplied initial prior variances are kept during fitting. Final trimming of variances below prior_tol still applies.

ELBO and residual variance

After each sweep, IBSS computes the expected residual sum of squares (ER2) and the evidence lower bound (ELBO). ER2 averages the squared residual over the posterior, accounting for uncertainty in the effects; Optimization describes its calculation from mu2 and the stored matrix products. The ELBO combines the expected log likelihood with a penalty for divergence from the prior:

L(q)=Eq[log⁡p(y∣b,σ2)]−∑ℓ=1LKL⁡{qℓ(bℓ)∥pℓ(bℓ)}. \mathcal L(q)=\mathbb E_q[\log p(\mathbf y\mid\mathbf b,\sigma^2)] -\sum_{\ell=1}^{L}\operatorname{KL}\{q_\ell(\mathbf b_\ell)\|p_\ell(\mathbf b_\ell)\}. L(q)=Eq​[logp(y∣b,σ2)]−ℓ=1∑L​KL{qℓ​(bℓ​)∥pℓ​(bℓ​)}.

The ELBO is evaluated at the current σ2\sigma^2σ2, and the stopping rule is checked before updating residual variance. If the stopping check does not terminate the fit and estimate_residual_variance=True, the ordinary Gaussian model updates σ2←ER2/n\sigma^2\leftarrow\mathrm{ER2}/nσ2←ER2/n, constrained by residual_variance_lowerbound and residual_variance_upperbound.

This update also runs after the last permitted sweep if the stopping check has not terminated the fit. Consequently, a fit that reaches max_iter can return a sigma2 different from the value used for its last ELBO; a converged fit skips the update. Final trimming of small prior variances leaves the recorded ELBO and fitted crossproduct unchanged. Results explains these returned quantities.

Stopping rules

The first sweep has no preceding state, so every rule is first evaluated after the second sweep (min_iter, default 2). The default ELBO rule (convergence_method="elbo") declares convergence when

0≤L(t)−L(t−1)<tol. 0\le\mathcal L^{(t)}-\mathcal L^{(t-1)}<\mathtt{tol}. 0≤L(t)−L(t−1)<tol.

A decrease does not satisfy it, and repeated posterior states are recorded only as diagnostics.

The PIP rule follows susieR and requires both

max⁡ℓ,j∣αℓj(t)−αℓj(t−1)∣<tolandmax⁡j∣PIPj(t)−PIPj(t−1)∣<tol. \max_{\ell,j}\bigl|\alpha^{(t)}_{\ell j}-\alpha^{(t-1)}_{\ell j}\bigr|<\mathtt{tol} \quad\text{and}\quad \max_j\bigl|\mathrm{PIP}^{(t)}_j-\mathrm{PIP}^{(t-1)}_j\bigr|<\mathtt{tol}. ℓ,jmax​​αℓj(t)​−αℓj(t−1)​​<tolandjmax​​PIPj(t)​−PIPj(t−1)​​<tol.

Each PIP uses the components whose VℓV_\ellVℓ​ exceeds prior_tol in the sweep in which the PIP was computed; as in susieR, the state preceding the first check is evaluated with the variances current at that check. If the condition fails but alpha and PIP both match the state kkk sweeps earlier within tol, for some 2≤k≤52\le k\le52≤k≤5, the fit is declared converged and alpha is replaced by the average of the kkk states in the cycle. The PIP rule is used:

  • with convergence_method="pip";
  • for slot-activity priors and for NIG with more than one effect;
  • by susie_rss with R_finite or R_mismatch, unless a convergence configuration is supplied, and always by multi-panel RSS;
  • for a sweep whose ELBO is NaN under the default ELBO rule, when no convergence configuration is supplied.

An infinite ELBO raises an error. A ConvergenceConfig passed as convergence selects the ELBO, alpha_pip or joint rule, with separate alpha_tol and pip_tol (default 1e-4), and can raise min_iter or lower the cycle lag. For R_finite, R_mismatch and multi-panel fits it must keep the default min_iter and cycle lag, and with R_finite or R_mismatch it can select only the ELBO rule; other settings raise ValueError. Convergence and refinement describes these rules and the recorded diagnostics.

From summaries to working sufficient statistics

The Gaussian likelihood depends on the data through Q\mathbf QQ, g\mathbf gg, sys_ysy​ and nnn. susie_suff_stat accepts these quantities directly. susie_rss constructs them from association summary statistics and LD, allowing the same regression model to be fitted when individual-level data are unavailable. The construction depends on which summaries are supplied and determines the units of the returned effects. The quantities below are constructed before the optional predictor standardization described above.

Known sample size and Wald z statistics

With z-scores and a known sample size nnn, the default z_method="wald" converts the marginal Wald statistics to the regression scale using

z~j=zjn−1zj2+n−2. \widetilde z_j=z_j\sqrt{\frac{n-1}{z_j^2+n-2}}. zj​=zj​zj2​+n−2n−1​​.

This adjustment accounts for the residual variance used in the denominator of a univariate Wald statistic. When var_y is omitted, the response is assigned unit sample variance and the working quantities are

Q=(n−1)R,g=n−1 z~,sy=n−1. \begin{aligned} \mathbf Q&=(n-1)\mathbf R,\\ \mathbf g&=\sqrt{n-1}\,\widetilde{\mathbf z},\\ s_y&=n-1. \end{aligned} Qgsy​​=(n−1)R,=n−1​z,=n−1.​

With z_method="score", the supplied statistics are used directly, z~j=zj\widetilde z_j=z_jzj​=zj​. Supplying bhat and shat without var_y also uses this construction after forming zj=β^j/SE⁡jz_j=\widehat\beta_j/\operatorname{SE}_jzj​=β​j​/SEj​. The returned coefficients are therefore on the standardized working scale; the units of the original effect estimates are not recovered from their ratio.

Effect estimates, standard errors and phenotype variance

Supplying bhat, shat, n and var_y together provides the information needed to reconstruct the original regression scale. Write vy=var_yv_y=\mathtt{var\_y}vy​=var_y and Aj=(n−1)/(zj2+n−2)A_j=(n-1)/(z_j^2+n-2)Aj​=(n−1)/(zj2​+n−2) for Wald statistics (Aj=1A_j=1Aj​=1 for score statistics). The reconstructed predictor sum of squares is

hj=vyAjSE⁡j2. h_j=\frac{v_y A_j}{\operatorname{SE}_j^2}. hj​=SEj2​vy​Aj​​.

The sufficient statistics are then

Qjk=hj Rjkhk,gj=z~jAj vySE⁡j,sy=(n−1)vy. \begin{aligned} Q_{jk}&=\sqrt{h_j}\,R_{jk}\sqrt{h_k},\\ g_j&=\frac{\widetilde z_j\sqrt{A_j}\,v_y}{\operatorname{SE}_j},\\ s_y&=(n-1)v_y. \end{aligned} Qjk​gj​sy​​=hj​​Rjk​hk​​,=SEj​zj​Aj​​vy​​,=(n−1)vy​.​

prusie averages the reconstructed matrix with its transpose to remove rounding asymmetry. If predictor standardization is enabled, it uses the reconstructed diagonal entries. coef reverses this standardization and returns effects per original predictor unit in the original phenotype units, under the supplied marginal-regression assumptions. mu and mu2 remain on the working predictor scale used during fitting.

Supplying z, var_y and n without bhat and shat uses a different construction:

Q=(n−1)R,g=n−1 z~,sy=(n−1)vy. \begin{aligned} \mathbf Q&=(n-1)\mathbf R,\\ \mathbf g&=\sqrt{n-1}\,\widetilde{\mathbf z},\\ s_y&=(n-1)v_y. \end{aligned} Qgsy​​=(n−1)R,=n−1​z,=(n−1)vy​.​

Here var_y changes the response sum of squares and the initial residual and prior variances. It does not reconstruct predictor scales or rescale g\mathbf gg by vy\sqrt{v_y}vy​​. To obtain coefficients on the original regression scale, supply the effect estimates and standard errors along with n and var_y.

Missing sample size

Without nnn, prusie uses a large-sample likelihood for noncentrality parameters. The working quantities are

Q=R,g=z,sy=1. \begin{aligned} \mathbf Q&=\mathbf R,\\ \mathbf g&=\mathbf z,\\ s_y&=1. \end{aligned} Qgsy​​=R,=z,=1.​

The internal calculation uses n=2n=2n=2 as a placeholder for this likelihood. Predictor standardization is disabled, and prior_variance sets the initial effect variance (default 50). If bhat and shat are supplied, their ratio provides the z-scores. A supplied var_y is validated and recorded but does not change these quantities. Returned coefficients describe noncentrality effects; original genotype and phenotype units cannot be recovered through this route. prusie issues a warning when the sample size is omitted.

Interpreting the LD approximation

R\mathbf RR must contain signed correlations for the same variants, in the same order and with the same effect-allele orientation as the association summaries. Inputs describes the required alignment. With LD from the study samples and matching regression preprocessing, the reconstruction can recover the individual-level regression quantities. With an external LD panel, it is an approximation whose accuracy depends on ancestry, reference sample size and data preparation.

Residual-variance estimation relies on LD consistent with the association study. Sampling noise or mismatch in a reference panel can affect that estimate. susie_rss defaults to estimate_residual_variance=False and warns when estimation is requested.

For case-control GWAS, RSS applies a Gaussian approximation to the association statistics. Quantitative eQTL summaries use their reported regression scale and sample size.

PIP and credible sets

The marginal posterior inclusion probability (PIP) summarizes evidence for a variant across the single-effect components. Let A\mathcal AA contain the components with Vℓ>prior_tolV_\ell>\mathtt{prior\_tol}Vℓ​>prior_tol. Under the variational approximation, the probability that at least one active component selects variant jjj is

PIPj=1−∏ℓ∈A(1−αℓj). \mathrm{PIP}_j=1-\prod_{\ell\in\mathcal A}(1-\alpha_{\ell j}). PIPj​=1−ℓ∈A∏​(1−αℓj​).

The product is the probability that all active components select other variants. Thus, αℓj\alpha_{\ell j}αℓj​ describes the location of one component, while PIPj\mathrm{PIP}_jPIPj​ combines evidence across components. Each row of α\alphaα sums to one; PIPs can sum to more than one because several variants may contribute to the trait.

A credible set CℓC_\ellCℓ​ summarizes uncertainty about the location of component ℓ\ellℓ. Variants are ranked by decreasing αℓj\alpha_{\ell j}αℓj​ and added until their cumulative posterior probability reaches coverage (default 0.95):

qℓ(γℓ∈Cℓ)=∑j∈Cℓαℓj≥coverage. q_\ell(\gamma_\ell\in C_\ell) =\sum_{j\in C_\ell}\alpha_{\ell j} \geq\mathtt{coverage}. qℓ​(γℓ​∈Cℓ​)=j∈Cℓ​∑​αℓj​≥coverage.

Adding the last variant can take the accumulated probability above the target. The returned posterior mass records this attained value. It describes the selected set under the fitted model; repeated-sampling coverage describes how often sets contain a true effect across repeated datasets and is assessed through calibration.

Credible sets are also screened for component activity, duplicate membership and LD purity. Purity summarizes the absolute pairwise correlations among set members. By default, the minimum absolute correlation must be at least 0.5 (min_abs_corr=0.5). A set of strongly correlated variants can have high posterior mass while leaving uncertainty about which member carries the effect. Results describes the activity thresholds, ordering, filtering options and returned component IDs.

Additional model options

A fixed mixture prior replaces a component's single Gaussian variance by

p(aℓ)=∑k=1KwkN(aℓ;0,vk),wk≥0,∑kwk=1. p(a_\ell)=\sum_{k=1}^{K}w_k N(a_\ell;0,v_k),\qquad w_k\geq0,\quad\sum_k w_k=1. p(aℓ​)=k=1∑K​wk​N(aℓ​;0,vk​),wk​≥0,k∑​wk​=1.

prior_variance_grid supplies positive vkv_kvk​ and mixture_weights supplies wkw_kwk​ (equal weights by default). The SER integrates over the grid and returns posterior mixture moments; it does not optimize one scalar variance in place of the mixture, and the returned V is the weighted mean variance ∑kwkvk\sum_k w_kv_k∑k​wk​vk​.

estimate_residual_method="NIG" uses the conjugate Normal–Inverse-Gamma formulation, with σ2∼IG⁡(α0/2,β0/2)\sigma^2\sim\operatorname{IG}(\alpha_0/2,\beta_0/2)σ2∼IG(α0​/2,β0​/2) and effect variance proportional to σ2\sigma^2σ2. Both hyperparameters must be positive; their default is 1/n1/\sqrt n1/n​. This integrates residual variance instead of the ordinary plug-in Gaussian SER. Computational compatibility

The numerical reference for the core fitting routines is susieR 0.16.6, commit 8e56a8e038e989856d106d9ca5175cc664fea9d2. prusie implements the Gaussian SuSiE model described above using float64 arithmetic in Python and Rust. Its computational optimizations reuse intermediate quantities, reduce matrix traversals and regroup arithmetic without changing the statistical model. Floating-point summation order and math-library implementations can differ from R, so agreement is assessed numerically; bitwise equality is not required.

A comparison uses the same inputs, verified variant order and matched fitting settings, including LLL, prior weights, variance estimation, standardization and stopping rules. It compares the complete final matrix of component inclusion probabilities, α\boldsymbol\alphaα. Let αℓjP\alpha^{\mathrm P}_{\ell j}αℓjP​ and αℓjR\alpha^{\mathrm R}_{\ell j}αℓjR​ be the values returned by prusie and susieR for component ℓ\ellℓ and variant jjj. Each case is summarized by its maximum absolute difference

Dα=max⁡ℓ,j∣αℓjP−αℓjR∣. D_\alpha=\max_{\ell,j}\left|\alpha^{\mathrm P}_{\ell j}-\alpha^{\mathrm R}_{\ell j}\right|. Dα​=ℓ,jmax​​αℓjP​−αℓjR​​.

Both matrices must have the same shape, with component rows and variant columns in their original order. The comparison includes inactive components and components without credible sets; no rows are omitted or permuted. Each alpha matrix must also contain finite probabilities in [0,1][0,1][0,1], with every row summing to one within 1e-10. No tolerance is imposed on DαD_\alphaDα​; the numerical accuracy page reports its distribution across the tested cases.

Marginal PIPs, credible sets, posterior moments, variances, Bayes factors, ELBOs and convergence metadata are compared separately, because a small numerical difference near a component-activity or credible-set threshold could change a reported summary. The fitting thresholds and stopping tolerances are those specified for the comparison.

The numerical accuracy page reports the tested configurations and recorded results. Agreement on those cases does not establish agreement for every input, model option or platform. Refinement has additional search controls and documented differences from susieR; core-fit agreement alone does not establish refinement equivalence.
