Numerical accuracy

Component posterior validation

Current core validation uses susieR 0.16.6, commit 8e56a8e038e989856d106d9ca5175cc664fea9d2, with identical arguments and verified variant order. The acceptance criterion is maximum absolute difference 1e-5 (relative tolerance zero) across the complete final alpha matrix, including inactive components and components without credible sets. Rows retain their original component order; they are never permuted to improve agreement. Each row must be finite, lie in [0, 1], and sum to one within 1e-10.

PIPs, credible-set memberships, moments, variances, Bayes factors, objectives, iteration counts and convergence flags remain diagnostics. Small differences near activity thresholds can change these summaries even when alpha agrees. The implementation uses mathematically equivalent float64 arithmetic rather than reproducing R rounding. No thresholds or stopping tolerances are relaxed for validation.

The current ordinary build passes all 415 fitted configurations with identical arguments and verified variant order:

Maxima are computed elementwise across every valid analysis, including iteration-limit outputs. The machine summary includes the case, array index, both values at the maximum and reference magnitude for each field. ELBO traces are compared only with matching shapes; per-case records retain any shape mismatch.

PIP and alpha differences have probability units. Conditional effects are on the fitted standardized predictor/phenotype scale for these z-input analyses; mu2 is a second moment, not a variance. Component and variant log Bayes factors use natural logarithms. Their numerical differences are recorded separately from PIP. ELBO is the iteration objective before final low-variance trimming; V, moments, Bayes factors and KL follow the finalization semantics described in results.

Sets are matched by original component ID and compared as member sets; returned ordering does not affect the comparison. All actual masses, purity statistics and zero-based members are retained.

The requested mass is 0.95. Returned mass is the sum of the selected alpha entries in the original component; purity uses every selected pair's absolute correlation. The retained numerical records include independent checks of PIP identity, alpha normalization, actual set mass and purity, including empty sets. Convergence and the presence of a credible set are different properties.

Independent toy example

The independent 500-variant toy example fit converged in 3 iterations and returned 2 credible sets. Its maximum absolute PIP difference from the separately generated susieR 0.16.6 reference was 1.66e-10.

The dashed lines mark the two simulated nonzero effects. This single toy example has its own newly executed reference, generation script and packaged inputs. See the toy example tutorial and vector PDF.

Reproduce the comparisons

Retained records include the real panel and a separately identified older synthetic regression panel. The older fixture and references remain byte-for-byte regression inputs. The installed package's independent toy example is checked against its separate packaged R reference by tests/test_packaged_example.py.

The reproducibility guide distinguishes regeneration from saved records, offline frozen-reference checks, and live-R fitting. tools/benchmark/compare_fits.py compares original component IDs and retains all field diagnostics. Existing frozen references and tolerances are unchanged.
