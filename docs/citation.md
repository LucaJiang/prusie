# Citation and license

Cite Wang et al. (2020) for the SuSiE model and fitting method. For analyses
using association summary statistics and linkage disequilibrium (LD), also cite
Zou et al. (2022) for SuSiE-RSS. The [statistical model](model.md) page
describes these methods.

- Wang G, Sarkar A, Carbonetto P, Stephens M (2020). A simple new approach to
  variable selection in regression, with application to genetic fine mapping.
  *Journal of the Royal Statistical Society: Series B (Statistical Methodology)*,
  82(5):1273–1300.
  [DOI: 10.1111/rssb.12388](https://doi.org/10.1111/rssb.12388).
- Zou Y, Carbonetto P, Wang G, Stephens M (2022). Fine-mapping from summary data
  with the “Sum of Single Effects” model. *PLOS Genetics*, 18(7):e1010299.
  [DOI: 10.1371/journal.pgen.1010299](https://doi.org/10.1371/journal.pgen.1010299).

Identify the software as **prusie 0.3.0**, by Wenxin Jiang, and record the source
revision and software environment used in your analysis.
[CITATION.cff](https://github.com/LucaJiang/prusie/blob/main/CITATION.cff) contains
machine-readable software citation metadata and the method references. It does
not list a DOI for prusie.
