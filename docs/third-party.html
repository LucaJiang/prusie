Locked Rust dependencies

The table records every registry component in Cargo.lock. Official source archives are available from https://static.crates.io/crates/NAME/NAME-VERSION.crate; their registry checksums are in the lockfile. No dependency source tree is vendored into the sdist. Runtime crates contribute code to the native extension; build and procedural-macro crates run during compilation. Their notices are retained conservatively for generated or embedded code. The project has no direct development-only Cargo dependencies.

For components offering MIT OR Apache-2.0, this distribution selects MIT. All original MIT copyrights, including notices that supply no named holder, are recorded in Rust-components.txt, with one identical common MIT grant. NumPy's Rust crate is BSD-2-Clause, separately from the Python NumPy dependency. unicode-ident additionally requires Unicode-3.0. target-lexicon uses Apache-2.0 with the LLVM exception.

Rust standard library and system libraries

Rust toolchain: 1.98.1. The standard library is statically linked into the native extension. Its runtime notices retain Rust, backtrace, channel, Unicode, compiler-builtins and libm attribution, and the notices for addr2line 0.25.1, adler2 2.0.1, cfg-if 1.0.4, gimli 0.32.3, hashbrown 0.17.1, libc 0.2.185, memchr 2.7.6, miniz_oxide 0.8.9, object 0.37.3 and rustc-demangle 0.1.27. These are separate from versions in the project's lockfile. Common terms are MIT, Apache-2.0, LLVM exception and Unicode-3.0. Compiler-builtins requires MIT and Apache-2.0 WITH LLVM-exception. Its original libm file notices additionally preserve Sun/fdlibm permission, David Schultz's BSD terms and CORE-MATH attribution.

The compiler executable and its development dependencies are not redistributed. Python, Python NumPy, and dynamically linked operating-system libraries are separately supplied dependencies; their full packages are not bundled in prusie. Building with another toolchain or for another platform requires reviewing its runtime notices before distributing the resulting wheel.
