# prusie artwork

Original artwork by Wenxin Jiang:

- `logo_title.jpeg`: banner and wordmark, 3584 × 1184.
- `logo.jpeg`: detailed logo, 2048 × 2048.
- `logo_small.jpeg`: simplified mark, 2048 × 2048.

The originals are preserved unchanged. Display copies are resized with their
original aspect ratios: `prusie-banner-1792.jpg`, `prusie-logo-384.jpg` and
`prusie-mark-96.png`. `favicon.ico` contains 16, 32 and 48 pixel copies of the
simplified mark. The banner and detailed logo link to their original files.
