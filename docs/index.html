Install Quick start Worked examples

One fit, a readable result

The packaged 500-variant synthetic toy example runs offline after installation. This code fits once and summarizes that posterior:

import prusie

example = prusie.load_example()
fit = prusie.susie_rss(**example["inputs"], **example["parameters"],
                       track_fit="compact", retain_data=True)
summary = prusie.summarize(fit, example["inputs"]["R"], z=example["inputs"]["z"])
print(prusie.summary_text(summary).splitlines()[0])
print(f"IBSS: {fit.convergence['stop_reason']} ({fit.niter} sweeps)")
for cs in summary["credible_sets"]:
    print(f"CS {cs['component_id']}: {', '.join(cs['members'])}")

Expected output:

500 variants; 2 retained credible sets; 2 active components.
IBSS: criterion_satisfied (3 sweeps)
CS 0: syn0100
CS 1: syn0350

The two singleton credible sets identify concentrated candidates in this toy fit. The quick start explains their PIPs and posterior mass, then adds plots and an offline report. Refinement, LD and sensitivity are separate explicit steps; they have not been run by the code above.

From candidates to interpretation

The stable example retains its two main CS across these settings, while a fixed positive scaled prior variance raises background probabilities. The worked examples explain this distinction and a second fit where refinement improves the solution but an LD-correlated pair remains unresolved.

Read the result in context

  • Reading results: which candidates carry support, and how concentrated is each signal?
  • Convergence and refinement: did IBSS stop, and can search improve the solution?
  • Sensitivity and LD: which conclusions change with settings or input assumptions?
  • Worked examples: how do these observations fit into a complete interpretation?
