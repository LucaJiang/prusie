Fine-mapping, from candidates to interpretation

prusie fits the SuSiE model to signed association statistics and LD. The Python API returns posterior inclusion probabilities (PIPs), credible sets and component posteriors, with optional convergence tracking, refinement, sensitivity comparisons and offline reports.

Start with the quick start to fit the packaged synthetic example. Then use the result to answer four questions:

Question Read next
Which candidates carry support, and how concentrated is each signal? Reading results
Did IBSS stop, and does a new search improve the solution? Convergence and refinement
Which conclusions change with settings or LD assumptions? Sensitivity and LD diagnostics
What does a complete interpretation look like? Worked examples

One fit and a short summary

import prusie

example = prusie.load_example()
fit = prusie.susie_rss(**example["inputs"], **example["parameters"],
                       track_fit="compact", retain_data=True)
summary = prusie.summarize(fit, example["inputs"]["R"], z=example["inputs"]["z"])
print(prusie.summary_text(summary))

The example returns two singleton credible sets after three sweeps. The quick start adds figures and an offline report without fitting again. Installation describes this 0.2.4.dev1 branch preview and optional analysis dependencies.

Two different diagnostic questions

In the stable example, fixing a positive component variance preserves the two leading CS but raises background PIPs.
