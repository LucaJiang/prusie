SuSiE fine-mapping in Python

prusie fits the Sum of Single Effects (SuSiE) regression model to association summary statistics and LD (SuSiE-RSS), or to sufficient statistics, and returns posterior inclusion probabilities (PIPs) and credible sets. The iterative Bayesian stepwise selection (IBSS) algorithm is implemented in Rust and follows susieR 0.16.6. Further functions report convergence, refinement, LD diagnostics and sensitivity to model settings.

Install Quick start Worked examples

One fit, a readable result

The packaged synthetic toy example with 500 variants can be fitted offline after installation. This code fits the model once and summarizes the posterior:

import prusie

example = prusie.load_example()
fit = prusie.susie_rss(**example["inputs"], **example["parameters"],
                       track_fit="compact", retain_data=True)
summary = prusie.summarize(fit, example["inputs"]["R"], z=example["inputs"]["z"])
print(prusie.summary_text(summary).splitlines()[0])
print(f"IBSS: {fit.convergence['stop_reason']} ({fit.niter} sweeps)")
for cs in summary["credible_sets"]:
    print(f"CS {cs['component_id']}: {', '.join(cs['members'])}")

Expected output:

500 variants; 2 retained credible sets; 2 active components.
IBSS: criterion_satisfied (3 sweeps)
CS 0: syn0100
CS 1: syn0350

Each of the two credible sets contains a single variant in this toy example. The quick start explains their PIPs and posterior mass and then produces figures and an offline report. Refinement, LD diagnostics and sensitivity analyses are separate steps that the code above does not run.

Sensitivity and refinement

In the toy example the two leading credible sets persist across these settings, whereas a fixed positive scaled prior variance increases the PIPs of other variants. The worked examples discuss this distinction and a second example in which refinement finds a solution with a higher objective, while a pair of variants in strong LD remains unresolved.

Reading a result

  • Reading results: which variants have posterior support, and how concentrated is each single effect?
  • Convergence and refinement: did IBSS satisfy its stopping rule, and does refinement find a solution with a higher objective?
  • Sensitivity and LD: which conclusions change with model settings or input assumptions?
  • Worked examples: how do these results combine in an interpretation?

The API, input guide and statistical model give the precise inputs, outputs and definitions. Reproducibility distinguishes regenerating figures from refitting models, and citation and license identifies the methods and the software version.
