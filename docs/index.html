prusie: SuSiE fine-mapping in Python

Fine-mapping seeks to identify variants that affect a trait despite uncertainty from linkage disequilibrium (LD). prusie fits SuSiE (Sum of Single Effects) models in Python with a Rust solver, allowing multiple effects within a region.

Fits accept association summary statistics with signed LD, centered sufficient statistics, or individual-level data. Results include component posterior probabilities (alpha), marginal posterior inclusion probabilities (PIPs) and credible sets. See the statistical model for assumptions and numerical accuracy for comparisons with susieR 0.16.6.

Installation

From the prusie 0.3.0 source checkout, use CPython 3.10–3.13 and install the build requirements, including the pinned Rust toolchain:

cd prusie
python -m venv .venv
. .venv/bin/activate
python -m pip install '.[analysis]' --config-settings=build-args="--locked"

NumPy is the only required Python dependency for core fitting. The optional analysis extra installed above adds SciPy for sparse inputs, LD diagnostics and advanced RSS models, and Matplotlib for plotting. Fitting does not require R. To install without Rust or a compiler, use a compatible prebuilt wheel.

Example

Fit the packaged 500-variant synthetic toy example offline and list its retained credible sets (CS):

import prusie

example = prusie.load_example()
fit = prusie.susie_rss(**example["inputs"], **example["parameters"])
summary = prusie.summarize(fit, example["inputs"]["R"], z=example["inputs"]["z"])
print(prusie.summary_text(summary).splitlines()[0])
print(f"IBSS: {fit.convergence['stop_reason']} ({fit.niter} sweeps)")
for cs in summary["credible_sets"]:
    print(f"CS {cs['component_id']}: {', '.join(cs['members'])}")

Expected output:

500 variants; 2 retained credible sets; 2 active components.
IBSS: criterion_satisfied (3 sweeps)
CS 0: syn0100
CS 1: syn0350

Component IDs are zero-based. The quick-start tutorial explains PIPs and credible sets, then adds figures and an offline report.

Memory retains the earlier local AMD EPYC 9754 measurements, including the interpreter, inputs and returned fit. Sensitivity and refinement

The official susieR toy example shows a fit that meets its stopping rule before refinement finds a higher evidence lower bound (ELBO). Refinement changes the singleton credible sets, while a set of strongly correlated variants remains unresolved.

Increasing the maximum number of single-effect components, L, retains the baseline's credible sets in this example. The saved report shows every retained credible set and separate LD panels for each set's top variant.
